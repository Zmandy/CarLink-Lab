# CarLink Lab 0.17.0：独立车载桌面

## 使用

新版 APK 可覆盖安装 0.16.1，沿用原调试签名和应用数据。

1. 手机“车辆连接”点击“开始连接”。
2. 电脑打开此前交付的 CarLink 模拟车机，选择手机，点击“连接 APP”。
3. 手机点击“显示独立车载桌面”。电脑显示横屏时钟、欢迎标题、车速和四轮胎压/胎温。
4. 返回手机桌面或熄屏，观察车机时钟继续变化。没有连接车辆时显示 `--`，不会填入演示读数。
5. 点击“恢复胎压仪表”可回到原仪表；“开始导航投屏”仍可共享现有导航应用。

独立桌面选择会保存，服务重启、视频暂停/恢复和车机重新连接后沿用。

## 当前能力边界

本次实现独立车载桌面，不包含独立地图、路线规划、导航播报或触摸反控。导航区域明确显示尚未接入。

独立桌面使用服务内的离屏 WebView 渲染，再经现有 H.264 编码和 CarLife 视频通道发送，不读取手机屏幕、不调用 MediaProjection。

真实地图 SDK 的 GPU 渲染不能直接假定可由当前软件 WebView 的 draw() 捕获。后续需接入地图 SDK，并单独验证地图显示、编码 Surface、定位生命周期和导航播报。已有手机导航投屏测试只证明共享导航画面的链路可用。
