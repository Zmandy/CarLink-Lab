# Open-source publishing checklist

## Before publishing

- [ ] Confirm the repository owner and repository name.
- [ ] Confirm whether the license is MIT or another license.
- [ ] Confirm the copyright holder in LICENSE.
- [ ] Review the legal and safety notices with a qualified professional if needed.
- [ ] Confirm that no proprietary firmware, official client code or signing material is included.
- [ ] Confirm that no VIN, plate, location, WiFi credential, token or private log is included.
- [ ] Build with JDK 17 and Android SDK 35.
- [ ] Confirm CI passes on main.

## GitHub settings

- [ ] Create the public repository.
- [ ] Set main as the default branch.
- [ ] Enable private vulnerability reporting.
- [ ] Protect main and require pull requests.
- [ ] Enable Dependabot alerts and updates.
- [ ] Add repository description and topics.
- [ ] Add a release with a signed or development APK only if redistribution is permitted.
