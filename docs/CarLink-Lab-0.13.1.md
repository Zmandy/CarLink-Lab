# CarLink Lab 0.13.1 说明

## 版本与文件

- APK：CarLink-Lab-0.13.1.apk
- 版本号：0.13.1
- versionCode：18
- 目标车辆：2015 / 2016 Hyundai Tucson TL 1.6T G4FJ
- 车机协议：百度 CarLife 本地 TCP 通道
- OBD 适配器：WiFi ELM327

本版按照已确认的 TPMS HTML 页面显示。Android 端使用 WebView 直接加载同一页面，再通过 JavaScript 注入实时 TPMS、燃油和欢迎标题数据，避免另写 Canvas 界面造成视觉差异。

APK 安装在安卓手机上。手机负责同时维持：

1. CarLife Head Unit 协议连接和 H.264 视频流。
2. WiFi ELM327 的 TPMS 与燃油数据轮询。
3. 安卓前台服务和 WiFi / CPU WakeLock，应用进入后台后仍保持连接。

## TPMS 数据

车辆确认使用 Mode 21：

- 请求头：7D6
- 请求：21 06
- 响应：61 06
- 每个传感器记录为 8 字节：

4 字节传感器 ID + 1 字节压力 + 1 字节温度 + 1 字节状态 + 1 字节序号

四组记录在响应数据中的起始偏移为：

2, 10, 18, 26

压力换算：

kPa = rawPressure / 4 × 6.894757

等价写法：

kPa = rawPressure × 1.72368925

温度换算：

°C = rawTemperature - 40

轮位映射：

| 记录 | 轮位 |
|---:|---|
| 1 | 左前 |
| 2 | 右前 |
| 3 | 左后 |
| 4 | 右后 |

必须使用传感器记录中的压力字节和温度字节，不能再把传感器 ID 字节作为压力或温度解析。

## 燃油消耗与油价

燃油数据优先读取标准 OBD-II PID：

- 015E：发动机燃油流量
- 失败时使用 0110 MAF 和 010D 车速计算
- 汽油换算参数：理论空燃比 14.7，汽油密度约 745 g/L

计算公式：

fuelRateLph = MAF / 14.7 / 745 × 3600

instantL100Km = fuelRateLph / speedKmh × 100

本次消耗量 = 燃油流量 × 采样时间累加

当前消费金额 = 本次消耗量 × 当日油价

界面直接显示：

- 本次消耗量 L
- 即时消耗 L/h
- 当前燃油标号单价
- 本次行程对应消费金额

油价接口：

https://api.qqsuu.cn/api/dm-oilprice?prov=省份

应用默认使用上海和 92#，可在 CarLife 客户端设置区修改省份与汽油标号。支持 89#、92#、95#、98#、0#。价格会缓存在本地；ELM327 WiFi 没有互联网时会继续使用最近一次有效价格，手机有可用移动数据时可在后台刷新。

## 使用步骤

1. 手机先连接 ELM327 的 WiFi。
2. 如果油价尚未缓存，确认手机移动数据可用，让应用联网刷新油价。
3. 打开 CarLink Lab 的 CarLife 客户端页面。
4. 设置标题、油价省份、汽油标号、ELM327 IP 和端口。
5. 点击“开始”，应用启动前台后台服务。
6. 开启 USB 调试，将手机连接到车机并启动 CarLife。
7. 返回桌面或切换其他应用后，服务仍会尝试保持 ELM327 和 CarLife 连接。

## 注意事项

- OBD 燃油流量推算属于诊断估算值，不等同于法定计量或车辆 ECU 的官方累计里程账单。
- 当前消费金额基于本次服务启动后的 OBD 采样累计，不是车辆总里程账单。
- TPMS 显示用于辅助观察，不能替代机械胎压表和正式诊断设备。
- ELM327 WiFi 热点通常没有互联网。若当日油价接口无法连接，应用会使用上一次成功获取并缓存的价格。
- 车机端 UI 的分辨率以实车协商结果为准；当前实车已验证为 800×480。
