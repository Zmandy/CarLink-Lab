# CarLink Lab 笔记本接续调试

> 本文记录 0.16.1 历史便携包，版本、依赖和验证范围不代表当前源码。当前状态请先看 README.md 和 amap-navigation-0.18.0.md；旧包不包含后来加入的高德 SDK 依赖。

当前版本：0.16.1 / versionCode 27，包名 `io.github.carlinklab`。

## 解压后直接使用

整包解压到一个短路径，例如 `C:\CarLink`。需要 Windows 10/11 x64；解压后的文件不要分开移动。不需要安装 Android Studio、JDK、Android SDK 或 Gradle。运行时仅在当前进程设置环境，不改系统环境变量。

双击根目录 `START.cmd`：

| 选项 | 用途 |
| --- | --- |
| 1 | 检查内置工具、查看已连接设备 |
| 2 | 配对并连接手机 |
| 3 | 覆盖安装 APK 并打开 APP，保留应用数据 |
| 4 | 显示并保存 CarLife / 编码 / 胎压 / 崩溃日志 |
| 5 | 离线构建当前源码，生成新 APK |
| 6 | 离线构建、5 项单元测试及 Android Lint |
| 7 | 打开已配置工具路径的 PowerShell，供手动 ADB 或构建 |
| 8 | 在切换手机热点前启用传统 TCP 5555 调试 |

也可以双击 `Install.cmd` / `Build.cmd` / `Verify.cmd` / `Debug.cmd`，分别安装、构建、验证、收集日志。

新笔记本需要获得手机调试授权；包内不复制台式机的 ADB 私钥。打开手机无线调试，使用新的配对地址和六位配对码。配对端口与连接端口通常不同：选项 2 先输入配对弹窗的地址和配对码，再输入无线调试主页面显示的连接地址。每次切换网络或重新开启调试后，连接 IP 和端口可能变化。

若使用 USB 调试，连接手机并接受授权；Windows 若不能识别手机，可能需要手机厂商 USB 驱动。使用无线调试不需要 USB 驱动。

## 手机热点与车机联调

手机 USB 接车机时，笔记本可尝试通过手机热点进行 ADB 调试。部分手机开热点时不允许启用配对码无线调试。可在当前 USB 或无线 ADB 仍连通时先选择 8，随后让笔记本连接手机热点，再选择 2：配对地址直接回车跳过，连接地址填写“手机热点 IP:5555”。手机热点 IP 通常是笔记本无线网卡的默认网关，不要继续使用原路由器网络的手机 IP。此方式仍需在你的手机上实测，重启后可能需重新启用。

传统 `adb tcpip 5555` 会重启 adbd，可能中断车机所使用的 USB/ADB 传输。请先停车验证原仪表能否重新连接；本包不会自动启用 TCP 或更改手机网络。

现有车辆方案还使用 WiFi ELM327。手机连接 ELM327 WiFi、同时开热点和使用移动数据的能力取决于手机系统与网络配置；必须实测确认。若连接热点后 ELM327 不可达，不要把车辆数据缺失误判成视频故障。

## 下一步实车测试

1. 停车后连接 ELM327 与车机，确认原胎压仪表正常。
2. 笔记本连接手机，选择 4 开始保存日志。
3. 手机车辆连接页选择“开始导航投屏”，授权共享导航应用或整个屏幕，随后打开导航，建议横屏。
4. 观察地图是否显示、持续更新、比例是否正常；运行约 10 分钟，记录延迟和发热。
5. 恢复胎压仪表，确认数据继续更新；再次投屏，检查重新授权和画面切换。
6. 检查系统停止共享、USB 拔插、车机重启、锁屏再解锁后的行为。

日志中的“导航首帧已编码并提交 CarLife 视频通道”不代表车机已成功解码；必须观察实际车机画面。

## 包内位置

- `CARLIFE`：本次所有源码修改、图标、测试和文档的快照，不依赖台式机上的项目目录。
- `APK`：可直接覆盖安装的 0.16.1 APK；构建后增加 `CarLink-Lab-latest.apk`。
- `tools`：Windows x64 JDK 17、Gradle 8.9、Android SDK Platform 35、Build Tools 34、ADB。
- `reference\files.zip`：用户提供的原始图标素材。
- `gradle-home`：离线构建依赖缓存，不包含账号、代理认证或 ADB 授权私钥。
- `logs`：运行菜单后保存构建和手机日志。
- `CARLIFE\signing\carlife-debug.keystore`：与已交付 0.15.0 / 0.16.1 一致的调试签名，仅用于自己的迁移和覆盖安装；不要提交到公开仓库。

固定工具可离线构建现有项目；新增依赖或升级 Android/Gradle 插件时，需要联网补充相应依赖。手机授权、网络互通以及车机/ELM327 连接仍是现场条件，便携包不会自动绕过。

## 给笔记本上的 Codex

打开解压包里的 `CARLIFE` 目录，先读本文件、`AGENTS.md` 和 `docs/navigation-projection-0.16.0.md`。Windows PowerShell 原生执行 `gradlew.bat`，不要调用 WSL。签名使用项目内相对路径，不覆盖密钥。先确认真实车机投屏和切换行为，再考虑车机触控、音频或导航 SDK。保留现有胎压仪表模式，避免为了导航改坏已验证的连接和采集链路。
